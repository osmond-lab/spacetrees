spacetrees
==========

Code to estimate dispersal rates and locate genetic ancestors from genome-wide genealogies.
Associated with the paper `Osmond & Coop 2024 <https://elifesciences.org/articles/72177>`_.

.. note::
   ``spacetrees`` was formerly referred to as ``sparg``. That name is now reserved for a
   separate project that infers spatial histories from full ancestral recombination graphs:
   `osmond-lab/sparg <https://github.com/osmond-lab/sparg>`_.
